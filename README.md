## 三个主打方向

### AI 懂我：越听，越懂你的喜好

从点心、听完、回听和切歌等行为中积累偏爱，让推荐贴近你的听歌习惯。主窗口的 **「AI懂你」** 是推荐入口；**「AI 学习与偏爱」** 可以开关学习、管理喜欢与不喜欢的记录。

想知道推荐依据，可以进入 **「看看 AI 学到了什么」**，查看偏好标签、行为统计、最近学到的内容和判断依据。也能指定一个音乐文件夹作为智能推荐范围。你可以复核并纠正记录，让偏爱由你掌握。

### AI 调音：让声音更合你的口味

右侧声音面板集中提供 **AI 母带、空间音频、动态增强与响度平衡**。AI 母带根据播放音源匹配音色与处理方案，面板显示当前处理状态和音源分析；空间音频由你手动选择。

保留直通、低音、人声、器乐与自定义音色，配合 **九段 EQ、音量和输出设备选择**。可以交给 AI 调整，也可以切回直通或自己调，让操作和声音变化都清楚可见。

### 精美界面：音乐、视觉与操作融为一体

黑金配色、大幅封面、动态歌词、实时点阵频谱与模拟 VU 表，组成 AURORA 的播放界面。常用声音控制放在右侧，播放控制放在底部，浏览曲库时也能继续操作。

播放面板背面提供 **玻璃 / 金属材质、透光、频谱灯光和氛围灯** 设置。既关注视觉，也照顾日常找歌、切歌与调音的便利，把界面、功能和音质放在同一套体验里。

2. 在「音乐库」添加文件 / 文件夹，或在「本地 / NAS」选择共享音乐目录。

## 常见问题

**全功能版的 AI 需要另买云端服务吗？** 目前这些功能根据本地音源分析和听歌行为运行，使用已实现的 AI 母带与推荐功能无需填写云端 AI API Key。

**歌曲简介和封面一定能查到吗？** 取决于本地标签、网络和公开数据库的覆盖。优先使用本地资料，再查询公开来源；缺乏可靠数据的字段会隐藏，不生成虚构内容。进入歌曲简介不会重新加载歌曲或改变播放队列。

**授权到期会丢失音乐和收藏吗？** 不会。高级功能停止开放，免费播放和已有数据保留。请妥善保存激活码，并通过「为爱发电」页面重新验证或续购。

**下载页里的 Source code 是播放器源码吗？** 不是。GitHub 自动生成的源码压缩包只包含此公开介绍仓库的文档和图片。运行程序请下载 EXE 或 Windows ZIP。

可在软件「设置 → 意见反馈」填写建议，点击「发送反馈」后在默认邮件程序中确认发送；软件不显示作者邮箱。也可提交 [GitHub Issue](https://github.com/Howard9088/AURORA_Player/issues)，附上版本、出现问题的界面和复现步骤；购买或订单问题可通过对应爱发电商品联系作者。反馈时请勿公开激活码或个人凭据。
