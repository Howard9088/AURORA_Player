AURORA 围绕你已有的音乐收藏设计：把电脑和 NAS 上的歌曲整理到同一个曲库，配上封面、歌词、音质信息和随音乐变化的频谱。全功能版进一步提供音源分析、声音增强和听歌偏爱学习，让播放与推荐逐渐贴近你的习惯。

此仓库公开产品介绍、界面图片和正式版下载。软件采用闭源共享软件许可，基础功能可免费使用。

## 核心功能

| 核心能力 | 你可以做什么 |
| :--- | :--- |
| **本地 / NAS 音乐库** | 导入文件或目录，按文件夹、专辑、收藏和最近添加浏览；读取 Windows 可访问的 NAS / SMB 共享目录。支持 FLAC、WAV、MP3、AAC、M4A、APE、ALAC 等常见格式，以及 CUE 整轨曲目。 |
| **沉浸式播放** | 查看封面、随进度变化的歌词和音质信息；实时点阵频谱与模拟 VU 表跟随音频变化。全功能版可调整面板材质、灯光、透光和氛围灯。 |
| **AI 母带与声音增强** | 根据音源特点选择音色与处理方案，配合动态增强、响度平衡和空间音频；可切回直通，或手工调整音色和九段 EQ。 |
| **AI 学习、AI DJ 与文件夹 AI** | 根据点心、听完、回听和切歌行为形成推荐；查看学习依据、调整偏爱记录，或只在指定文件夹内生成智能播放列表。 |
| **歌曲资料与曲库维护** | 自动匹配缺失的歌词和封面，查询歌曲、歌手、专辑及创作资料；检查重复歌曲。全功能版提供缺失标签补齐。歌曲简介直接展示公开资料，不用 AI 编造内容。 |

## 下载与开始使用

| 下载 | 说明 |
| :--- | :--- |
| [Windows 64 位 EXE](https://github.com/Howard9088/AURORA_Player/releases/latest/download/AURORA_Player.exe) | 单文件正式版，下载后运行。 |
| [Windows 64 位 ZIP](https://github.com/Howard9088/AURORA_Player/releases/latest/download/AURORA_Player_NativeProtected_v2.1.0_Windows_x64.zip) | 包含程序、使用说明和校验信息，解压后运行。 |
| [SHA256 校验文件](https://github.com/Howard9088/AURORA_Player/releases/latest/download/SHA256.txt) | 核对下载文件完整性。 |

1. 下载并打开 `AURORA_Player.exe`。
2. 在「音乐库」添加文件 / 文件夹，或在「本地 / NAS」选择共享音乐目录。
3. 双击歌曲开始播放；在「设置」调整语言、歌词 / 封面匹配和曲库维护选项。

NAS 目录需先能在 Windows 文件资源管理器中访问。当前下载包为 Windows 桌面版，不包含 NAS 网页服务或手机安装包。播放本地音乐不要求联网；在线资料、电台和全功能授权核验需要联网。

## 常见问题

**全功能版的 AI 需要另买云端服务吗？** 目前这些功能根据本地音源分析和听歌行为运行，使用已实现的 AI 母带与推荐功能无需填写云端 AI API Key。

**歌曲简介和封面一定能查到吗？** 取决于本地标签、网络和公开数据库的覆盖。优先使用本地资料，再查询公开来源；缺乏可靠数据的字段会隐藏，不生成虚构内容。进入歌曲简介不会重新加载歌曲或改变播放队列。

**授权到期会丢失音乐和收藏吗？** 不会。高级功能停止开放，免费播放和已有数据保留。请妥善保存激活码，并通过「为爱发电」页面重新验证或续购。

**下载页里的 Source code 是播放器源码吗？** 不是。GitHub 自动生成的源码压缩包只包含此公开介绍仓库的文档和图片。运行程序请下载 EXE 或 Windows ZIP。
